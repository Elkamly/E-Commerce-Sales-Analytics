# E-Commerce Sales Analytics & Data Warehouse

An end-to-end E-Commerce Sales Analytics project built using **MySQL** and **Microsoft Power BI**.

The project focuses on building a structured analytical data warehouse, preparing and modeling the data in Power BI, creating DAX-based KPIs, and developing an interactive dashboard for business analysis.

---

## 📌 Project Overview

This project transforms e-commerce transactional data into an analytical solution that provides insights into:

- Sales Revenue
- Orders
- Customers
- Product Categories
- Seller Locations
- Delivery Performance
- Customer Reviews
- Order Status

The solution uses **MySQL as the data warehouse** and **Power BI as the analytics and visualization platform**.

---

## 🏗️ Project Architecture

```text
E-Commerce Data
       |
       v
     MySQL
       |
       v
  Data Warehouse
   ecommerce_dw
       |
       v
    Power BI
       |
       +---- Power Query
       |
       +---- Data Model
       |
       +---- DAX
       |
       v
   Interactive
    Dashboard
```
| Technology  | Purpose                              |
| ----------- | ------------------------------------ |
| MySQL       | Database and Data Warehouse          |
| SQL         | Database design and querying         |
| Power BI    | Data analysis and visualization      |
| Power Query | Data cleaning and transformation     |
| DAX         | Business calculations and KPIs       |
| VS Code     | SQL script editing and project files |
